طريقة استخراج ملف APK من هذا المشروع:
1. فك الضغط عن الملف Haflati-Android-Project.zip
2. افتح المجلد HaflatiAndroid عبر برنامج Android Studio (Ladybug أو أحدث)
3. انتظر اكتمال مزامنة Gradle ثم اختر من القائمة العلوية:
   Build > Build Bundle(s) / APK(s) > Build APK(s)
4. ستجد ملف app-debug.apk جاهزاً للتثبيت على أي هاتف أندرويد بواجهة RTL عربية كاملة.
ملاحظة: يمكنك وضع ملفات خط IBM Plex Sans Arabic (.ttf) داخل app/src/main/res/font/ وتفعيلها في Theme.kt.
